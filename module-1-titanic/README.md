# Модуль 1: EDA и бинарная классификация (Titanic)

Этот модуль содержит решение задачи бинарной классификации пассажиров Титаника в рамках курса «Машинное обучение и ИИ».

## Структура модуля

- `data/` — исходные датасеты (`train.csv`, `test.csv`).
- `examples/` — сохранённые графики EDA, ROC-кривые и матрицы ошибок.
- `models/` — обученные модели (`lr_model.pkl`, `dt_model.pkl`), энкодеры, скалер и метрики в формате JSON.
- `notebook.ipynb` — Jupyter Notebook с полным циклом исследования и обучения моделей.
- `requirements.txt` — список необходимых библиотек для воспроизведения результатов.

## Основные результаты

В ходе работы были обучены и сравнены две модели: **Logistic Regression** и **Decision Tree**. Метрики качества и графики сохранены в папках `models/` и `examples/`.
